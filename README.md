# SkinStudio Static HTML/CSS Prototype

Static HTML/CSS prototype for the SkinStudio homepage and e-shop layout.

## Project purpose

This repository is used for developing and testing the visual structure of the SkinStudio website before moving selected parts into WordPress / WooCommerce.

Main goals:

- test homepage sections;
- adjust spacing and layout;
- improve responsive behavior;
- organize images and assets;
- track design changes with Git and GitHub.
